# Markers

This is the list of all markers present in [![GitHub Release](https://img.shields.io/github/v/release/izsvenezie-virology/FluMut?label=FluMut)](https://github.com/izsvenezie-virology/FluMut/releases/latest/).

{: .note}
Mutations on HA's proteins are reported with H3 numbering.
Mutations on NA's protein are reported with N1 numbering.
FluMut maps these positions on the reference of each HA (H1–H16) and NA (N1–N9) subtype, so you don't have to renumber your sequences.
